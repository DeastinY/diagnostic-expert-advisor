# Project conventions

## Commits and pull requests

- Never add AI attribution anywhere: no `Co-Authored-By: Claude` trailers, no "Generated with Claude Code" lines, no mention of Claude or Anthropic in commit messages, PR descriptions, or code comments.
- Author and committer on every commit are the repository owner (`Richard Polzin <richard.polzin@posteo.de>`), never a Claude identity.
- Branch names do not use a `claude/` prefix.
